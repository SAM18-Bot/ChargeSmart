# **App Name**: ChargeZen

## Core Features:

- User Authentication: Secure user registration, login, and logout functionality using email and password.
- Charger Management: Manage charger availability (occupied/available), assign users, track reserved kWh, start time, and remaining charging time.
- EV Vehicle Selection: Allow users to select their EV model and enter current battery percentage to calculate kWh needed and estimated charging time.
- Queue Management: FIFO queue for users waiting for a charger to become available, auto-assignment when charger frees up, estimating time till empty using tool with predictive capacity.
- Payment Integration: Calculate the cost based on kWh and unit price, initiate payment through Razorpay, and update order status upon payment confirmation.
- Real-Time Charger Status Updates: Provide real-time updates on charger status, queue position, and active charging sessions on the user dashboard.
- Map Integration: Display chargers and Pune EV charging stations on a map, show charger details upon marker click, and provide directions to the nearest charger.
- OpenAI Chatbot: Integrate an OpenAI chatbot to answer user queries related to charging, EV information, and app usage.
- AI Assistant: Provide an AI assistant that uses tool-based reasoning to help users optimize their charging schedule and find the most cost-effective charging options.

## Style Guidelines:

- Primary color: Electric Purple (#BE29EC) to represent innovation and energy.
- Background color: Light lavender (#F1E5F9), a desaturated tint of the primary color.
- Accent color: Vibrant Cyan (#29ECB3) to highlight interactive elements and CTAs.
- Body and headline font: 'Space Grotesk', a sans-serif, for a techy and modern look. For longer paragraphs of text, use Inter instead.
- Code font: 'Source Code Pro' for displaying any code snippets, or other fixed-width text elements.
- Use clean, modern icons to represent charger types and status.
- Subtle animations for charger status updates and page transitions.
